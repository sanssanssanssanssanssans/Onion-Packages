# Onion Packages Lite (공개 버전)

**Onion Packages Lite**는 양파 어드민 점프맵 프로젝트에서 사용되는 Onion 패키지 중  
커뮤니티에 공유해도 안전한 모듈들만 추출해 공개한 “경량 공개 패키지”입니다.

단순한 유틸리티, UI 기능등, 개발자에게 도움이 되는 범위만 안전하게 포함했습니다.

## 포함되지 않은 내용

- 권한 관리(어드민 시스템)
- Onion Admin 핵심 기능 전반

이 패키지는 어디까지나 **점프맵 개발자 친화적 공개 리소스**이며,  
운영 및 보안 기능은 숨김 처리되었습니다.

## 설치 방법

1. 이 저장소를 다운로드합니다.
2. `modules/` 안의 ModuleScript들을 Roblox Studio의 `ReplicatedStorage`에 넣습니다.
