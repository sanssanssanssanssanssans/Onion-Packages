# 소개

Onion Packages Lite는 양파 어드민 점프맵 개발을 돕기 위해 만들어진 공개 모듈 모음입니다.

원본 Onion 패키지는 양파 어드민 점프맵 서버 전용으로 설계된 커스텀 구조이며  
개인 서버, 프라이빗 환경, 특정 권한 시스템에 종속되는 요소가 포함되어 있습니다.

그렇기 때문에 원본 전체를 공개할 수는 없으며,  
안전하게 공개 가능한 일부 모듈만 선택적으로 제공하는 형태가 바로 이 Lite 버전입니다.

Lite 패키지는 다음 목적을 갖습니다:

1. 어드민 점프맵 개발자에게 간단한 기능 제공  
2. 안전하게 재사용 가능한 코드 제공
