# Onion Packages Lite 기여 안내

오류 제보, 기능 제안, 개선 PR은 언제나 환영합니다.  
단, 다음 내용을 반드시 참고해주세요.

---

## 1. 기여 가능한 범위

- 공개 모듈 개선
- 버그 수정
- 문서(README, docs) 수정
- 예제 코드 추가

---

## 2. 코드 스타일 규칙

- Roblox-Luau 표준 문법 준수
- 변수명 의미 있게 작성
- 불필요한 연산/중복 제거
- 클라이언트 신뢰 금지

---

## 3. PR 제출 방법

1. Issue로 먼저 제안하거나 바로 PR 제출 가능
2. 변경 이유와 목적을 명확히 서술
3. 테스트 가능한 환경/조건을 함께 작성
4. 민감한 문자열이나 운영 코드 포함 금지

---

## 4. 감사의 말

커뮤니티 참여는 프로젝트를 더욱 나아지게 만듭니다.  
기여해주는 모든 분께 감사드립니다.
